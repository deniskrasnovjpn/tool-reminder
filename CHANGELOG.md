# Changelog

## 0.2.0

- New command `tips`: turns the catalog into Claude Code spinner tips, each a command plus its index line or the
  entry's own `Tip:` line, that replace the built-in ones. Your own tips stay, and Claude offers to refresh the catalog tips after the catalog
  changes.

## 0.1.0

- First release: the catalog check at session start and on every prompt, setup with import of the older toolbox
  catalog, and the commands index, add, remove, edit, revision and setup.
